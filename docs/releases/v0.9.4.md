## AI Usage Dashboard v0.9.4

A patch release that fixes Claude login renewal on Windows, shows Claude's saved limit resets, and lets you remove a saved DeepSeek key.

### Fixes

- **Claude renewal on Windows.** When the Claude login expired, the dashboard could not start Claude Code to renew it on Windows, so the Claude card stayed empty. It now starts Claude Code through its npm `.cmd` shim, answers the console's startup cursor query so Claude Code does not stall, and stops the whole process tree afterwards.
- **Claude scoped weekly fallback.** When the all-models weekly window is missing, the 7D figure is the most constrained model-specific weekly window, not simply the first one listed.

### Added

- **Claude saved resets.** Resets you can redeem ("Reset for free" in Claude's usage settings) appear on the Claude card's BANKED RESETS line with the earliest expiry. If the server rejects that query, usage still loads without it.
- **Codex `chatgpt_base_url`.** A top-level `chatgpt_base_url` in the `config.toml` next to `auth.json` is followed, as the Codex CLI does. Only https addresses are used.
- **Clear DeepSeek key.** Display Settings shows CLEAR beside the DeepSeek key when one is saved; save to delete it from the per-user config. A key set through `DEEPSEEK_API_KEY` is not affected.

### Changed

- **Antigravity reset times on ring cards.** The grouped chips on a small Antigravity ring show a short reset after the percentage: the date for 7D, the time for 5H. The narrowest six-card layout (960×540) still hides them so the ring keeps its size.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.4_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.3 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

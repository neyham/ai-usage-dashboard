## AI Usage Dashboard v0.9.2

A patch release for the OpenCode Go card added in 0.9.1.

### Fixes

- **OpenCode Go character in ring cards.** The ring art was an enlarged crop of the corner art, so the character filled the circle and looked larger than the other five. It is redrawn as a centred, waist-up pose at the same scale, in all five moods. Wide cards keep the corner art.
- **Spent OpenCode Go windows.** A window at 100% was shown as NOMINAL while the server still reported `ok`. A full window now shows QUOTA EXHAUSTED with a LIMIT chip, whatever the status says. Another status counts only when it names a limit.

### Changed

- The app and package descriptions list OpenCode Go.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.2_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.1 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

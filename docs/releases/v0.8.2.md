## AI Usage Dashboard v0.8.2

This release changes how two, three, and four provider cards fill the board.
Two sit side by side as near-square rings. Three use a T. Four use a 2×2 of
landscape cards. One, five, and six layouts are unchanged.

### Highlights

- **Two panels:** side-by-side near-square IP ring posters instead of stacked
  landscape bars.
- **Three panels:** a T — the first enabled provider spans the top row; the
  other two sit side by side below (`PROVIDER_ORDER`).
- **Four panels:** a 2×2 of landscape cards (labeled bars on the default IP
  skin) instead of four portrait columns.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.2/AI-Usage-Dashboard_0.8.2_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.2 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.2) and accompanied by `AI-Usage-Dashboard_0.8.2_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.

## AI Usage Dashboard v0.9.6

A patch release that reads Claude Code's macOS Keychain login, restores Claude saved limit resets ("Reset for free"), hides expired cached windows, reuses refreshed Antigravity tokens in memory, and adds a sanitized diagnostic log.

### Fixes

- **Claude login on macOS Keychain.** Claude Code stores the default profile's login in the macOS Keychain item `Claude Code-credentials` rather than in `~/.claude/.credentials.json`. The dashboard now reads that Keychain item through `/usr/bin/security` before falling back to files, so macOS cards no longer show `LOGIN REQUIRED`, and renewal through the `claude` command covers Keychain logins too.
- **Claude saved limit resets ("Reset for free").** The Claude usage endpoint now returns saved limit resets only to requests identifying as a recent Claude Code CLI. The usage request now sends `claude-cli/<version> (external, cli)` using the newer of `claude --version` (checked at most every six hours through `claudeCodeCommand`) and `2.1.323`.
- **Expired cached windows and saved-reset counts.** Cached windows whose reset time has passed, and saved-reset counts past their earliest expiry, are dropped rather than shown as current until the next live refresh succeeds.
- **Antigravity token refresh reuse.** An access token refreshed in memory and the working OAuth client are reused until the token expires instead of rescanning the `agy` binary and requesting a new token on every refresh cycle.

### Added

- **Sanitized diagnostic log (`diagnostics.log`).** Written beside `state.json` whenever a provider's outcome changes, plus the reason a Claude or Antigravity login renewal failed. Contains timestamps, provider names, status text, HTTP status codes, and error descriptions with the home directory shortened to `~`—never tokens, keys, or response bodies. Capped at 256 KiB with one backup (`diagnostics.log.1`), mode `0600` on macOS/Linux, and skipped in offline demo mode.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.6_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.5 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

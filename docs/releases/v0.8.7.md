## AI Usage Dashboard v0.8.7

A refreshed dashboard with complete Grok artwork, clearer provider styling, and more conservative Claude credential recovery.

### Highlights

- Refined Cursor and Antigravity mascots and backgrounds, plus complete Grok twin tails across all five expressions.
- Six-card layout: Codex, Claude, Antigravity, Grok, Cursor, DeepSeek. Smaller layouts retain their existing order.
- Grok uses the combined account credit percentage when available.
- Claude displays recognized subscription tiers, uses valid credentials before attempting recovery, and rereads credentials already renewed by Claude Code.
- Claude recovery delegates to the official CLI without sending a model prompt. Hooks and tools are disabled only in that recovery process; regular Claude Code settings remain unchanged.
- Release binaries remap local source/toolchain paths. Updated affected Rust and npm dependencies.

### Installation

Download the installer for your platform from this release:

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The existing `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.8.7_SHA256SUMS.txt`.

### Compatibility and limits

- Native CI checks cover installation from the published 0.8.6 packages, replacement/upgrade to 0.8.7, synthetic-data startup, repeat installation/repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.
- Claude credential recovery is **best effort**, not a guaranteed unattended refresh. Real expired-account renewal is not covered by the synthetic tests. Keychain-only Claude logins on macOS are currently unsupported; the fetcher reads credential files.
- Windows screensaver and scheduled-idle helpers remain Windows-only.

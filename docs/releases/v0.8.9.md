## AI Usage Dashboard v0.8.9

A Linux reliability fix plus a privacy and dependency update. **Linux users on 0.8.7 or 0.8.8 should upgrade.**

### Highlights

- **Linux:** On Ubuntu 24.04, procps 4.0.4's `kill` reads `-KILL -19` as `kill(-1)`. So when a stuck Claude Code login probe was stopped, the app could also kill other processes owned by the same user. The process-group ID now comes after `--`.
- The usage cache (`state.json`) is created owner-only (`0600`) on Linux and macOS. Files written by older versions are tightened when loaded. The cache has usage and balance data but no credentials.
- Codex usage requests send `Accept: application/json`.
- Update Tauri to 2.12, Vite to 8, and `@vitejs/plugin-react` to 6, plus Playwright, PostCSS, and tokio. Drop the unused rustls TLS backend; every provider already used the OS TLS stack.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.8.9_SHA256SUMS.txt`.

### Compatibility and limits

- Building from source now needs Rust 1.90+ and Node.js 20.19+ or 22.12+.
- The release workflow tests upgrades from the published 0.8.8 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.
- Claude credential recovery remains best effort. Synthetic tests do not cover renewing a real expired account, and Keychain-only Claude logins on macOS remain unsupported.
- Windows screensaver and scheduled-idle helpers remain Windows-only.

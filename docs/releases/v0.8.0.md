## AI Usage Dashboard v0.8.0

This release restyles the IP mascots, splits Cursor usage into Included / Auto
/ API, and makes compact rings follow the hotter quota window.

### Highlights

- **Mascots:** Grok, Cursor, and Codex share DeepSeek's dumpling clay-chibi
  look. Grok is a lime-and-black Mars girl with a rocket hair clip; Cursor is a
  long-haired mouse girl without a tail; Codex is a mint headset operator.
- **Cursor lanes:** Included, Auto, and named-model API usage are three labeled
  percentages. Compact Cursor cards use the ring; wide cards keep the bars.
- **Compact rings:** a small card draws the hotter of its outer/inner windows,
  so a spent 5-hour Codex or Claude quota is not hidden behind a calm 7-day arc.
- **Antigravity plan:** Google AI Pro/Ultra come from `paidTier` or a real tier
  id. The featured number is the 7-day window.
- **Grok resets:** banked usage-limit resets appear when the account still has
  any remaining.
- **Classic EVA:** Display Settings can switch to segmented NERV-style bars
  with no mascots.
- **README:** synthetic screenshots for five-panel IP, six compact rings, and
  classic EVA.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.0/AI-Usage-Dashboard_0.8.0_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.0 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.0) and accompanied by `AI-Usage-Dashboard_0.8.0_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

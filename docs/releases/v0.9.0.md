## AI Usage Dashboard v0.9.0

Support for **The X Subscription** (launched 2026-10-12), plus Antigravity's Claude quota.

### Highlights

- **One X card for Grok and Cursor.** A switched seat has one weekly pool shared by Grok and Cursor. When Grok's billing endpoint reports that pool, the dashboard shows a single X card instead of two cards that each look like a separate quota. Enabling either Grok or Cursor is enough. The weekly total is one bar split by product (Chat, Bot, Build, and Cursor when it has usage), with the reset time. The pool is read through the official Grok Build login, so the Grok CLI must be signed in.
- **Unswitched accounts are unchanged.** SuperGrok, Cursor, and X Premium plans that have not moved over keep their separate Grok and Cursor cards. The switch is decided from the server's unified-billing flag and product breakdown, not from plan names.
- **Antigravity Claude quota.** Antigravity's "Claude and GPT models" group is now shown under its own heading, beside Gemini. The headline percentage is the tightest window.
- X Subscription tier names (Plus, Premium, Super, Ultra) are recognized. Some switched seats are still reported as "SuperGrok" by xAI; the X card hides that legacy name.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.0_SHA256SUMS.txt`.

### Compatibility and limits

- The X pool comes from Grok's billing endpoint. A Cursor-only install (no Grok CLI login) keeps the legacy Cursor card; Cursor's own usage feed for switched seats has not been verified yet.
- xAI does not publish absolute pool sizes; the card shows the server-reported percentage.
- Prepaid credit is read but not displayed.
- The release workflow tests upgrades from the published 0.8.9 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

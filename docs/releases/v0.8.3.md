## AI Usage Dashboard v0.8.3

This release stops Cursor from sticking on `AUTH FORBIDDEN` when an unexpired
CLI session is rejected. The dashboard matches CodexBar's session cookie and
tries the next local login.

### Highlights

- **Cursor cookie:** `WorkosCursorSessionToken` uses the cursor.com / CodexBar
  form `userId%3A%3Atoken`. If that encoding is rejected, the decoded `::`
  form is tried next. `GET /api/usage-summary` no longer sends `Origin`.
- **Rejected session fallback:** a `401`/`403` from `usage-summary` tries the
  next local login instead of stopping on `AUTH FORBIDDEN`.
- **Linux logins:** also reads `~/.cursor/auth.json` and the
  `cursor-access-token` secret-tool item.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.3/AI-Usage-Dashboard_0.8.3_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.3 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.3) and accompanied by `AI-Usage-Dashboard_0.8.3_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.

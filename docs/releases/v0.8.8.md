## AI Usage Dashboard v0.8.8

A small visual-polish release for the IP skin's circular gauges.

### Highlights

- Lower Cursor and Antigravity artwork within the circular mask.
- Enlarge and lower Grok artwork to hide the sprite's straight waist edge.
- Refresh the four-card and six-ring README screenshots using synthetic data.
- Release checks read the candidate version from package metadata, reject mismatched tags, and use 0.8.7 as the native upgrade baseline.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.8.8_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow checks upgrades from the published 0.8.7 packages, synthetic-data startup, repeat installation or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.
- Claude credential recovery remains best effort. Real expired-account renewal is not covered by synthetic tests, and Keychain-only Claude logins on macOS remain unsupported.
- Windows screensaver and scheduled-idle helpers remain Windows-only.

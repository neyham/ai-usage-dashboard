## AI Usage Dashboard v0.6.0

This release adds a cross-platform Low Power Mode for dashboards that stay
open for long periods, with a particular focus on Linux WebKitGTK devices.

### Highlights

- **Low Power Mode:** enable it from Display Settings on Windows, macOS, or
  Linux. The preference is saved as `lowPowerMode` and applies immediately.
- **Much lower renderer load:** decorative animation, scanlines, vignette,
  radar overlays, transitions, and expensive glow composition are disabled.
- **Quieter updates:** the clock updates once per minute, hidden windows pause
  renderer work, and automatic provider refreshes use a 15-minute minimum.
  Startup and manual refresh remain available.
- **Measured on Surface Linux:** repeated fullscreen tests reduced the combined
  Dashboard and WebKit process-tree CPU load from about 88% to 0.2–0.5% while
  Codex, DeepSeek, and Grok continued to report live nominal data.
- **Compatibility:** existing configuration files default to full effects until
  the user enables Low Power Mode; credentials and provider data are unchanged.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.6.0/AI-Usage-Dashboard_0.6.0_x64-setup.exe).

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/download/v0.6.0/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/download/v0.6.0/install-macos.sh | sh
```

All published assets are listed in the [v0.6.0 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.6.0) and accompanied by `AI-Usage-Dashboard_0.6.0_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only; Grok Build remains opt-in.

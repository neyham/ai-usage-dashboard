## AI Usage Dashboard v0.9.5

A patch release that fixes Antigravity token refresh with current `agy` builds, keeps an untouched X pool on one card, and updates dependencies.

### Fixes

- **Antigravity token refresh with agy 1.4 and later.** When the saved Antigravity access token had expired, the dashboard could not refresh it and showed SESSION EXPIRED. Newer `agy` binaries pack the OAuth client secret next to other identifier bytes, so the scanned value was a few characters too long and Google rejected it. The scan now tries the standard secret lengths first, so refresh works again without re-running `agy`.
- **X pool right after a weekly reset.** When the credits response named the unified X pool but omitted every usage figure, the card split into Grok and Cursor and showed `--%`. It now stays one X pool card at 0% inside the current period.
- **Cursor-only cached X card.** With only Cursor enabled, a cached X pool card now counts as cached data, so the summary reads partial instead of empty.

### Changed

- Dependencies: reqwest 0.13.4, dirs 7.0.0, tokio 1.54.0, serde_json 1.0.154, tauri-build 2.7.2, lucide-react 1.57.0, @fontsource/jetbrains-mono 5.3.0, postcss 8.5.31, playwright 1.64.1.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.5_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.4 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

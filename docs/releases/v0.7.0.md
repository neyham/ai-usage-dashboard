## AI Usage Dashboard v0.7.0

This release adds opt-in Cursor and Antigravity quota panels, a default IP
color-slab skin, and plan-tier five-panel layout. It also stops embedding
Google OAuth client secrets.

### Highlights

- **Cursor (opt-in):** included monthly usage, named-model API usage, plan, and
  billing-cycle reset from the official CLI login or desktop session.
- **Antigravity (opt-in):** Gemini 5-hour and weekly quota from the official
  `agy` login or OS keyring. Expired access tokens may refresh in memory
  using env overrides, login JSON client fields, or a scan of installed `agy` /
  Antigravity.app. Google client secrets are not stored in this repository.
- **IP color slabs:** default art skin with original mascot restyles. Wide
  top-tier cards use labeled bars; compact cards keep the dual ring. Display
  Settings can switch back to the ring-gauge HUD.
- **Plan-tier layout:** five panels fill the board. SuperGrok Heavy, Cursor
  Ultra/Enterprise, or Google AI Ultra take the large slots.
- **Windows credentials:** native files only. WSL credential paths are gone.
- Cursor and Antigravity stay **off by default** so an upgrade never starts
  reading a new credential source without an explicit selection.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.7.0/AI-Usage-Dashboard_0.7.0_x64-setup.exe).

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.7.0 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.7.0) and accompanied by `AI-Usage-Dashboard_0.7.0_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only. Grok Build, Cursor, and Antigravity remain opt-in.

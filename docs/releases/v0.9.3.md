## AI Usage Dashboard v0.9.3

A patch release that brings back the Antigravity Gemini quota, adds the separate Gemini 4 Argon quota, and headlines every card with its 7-day figure.

### Fixes

- **Antigravity without a Gemini group.** Since 2026-10-16 the Antigravity quota summary could return only the "Claude and GPT models" group, and the card failed. A missing group no longer fails the card; only a summary with no usable window is an error.
- **Antigravity Gemini quota restored.** The summary returns only the groups the calling client version knows. The quota request now names the current Antigravity CLI version, so Gemini comes back.
- **Per-bar warning colours.** A usage bar past 70% / 88% turns amber / red again.
- **Rate-limit state from cache.** A cached summary shows RATE LIMITED for any provider still in its 429 cooldown, not only Claude.
- **OpenCode Go credentials.** A configured credentials file that cannot be read or parsed reports CREDENTIAL ERROR; an oversized `auth.json` is rejected instead of truncated.
- **Antigravity keychain login.** The `go-keyring-base64:` keychain entry written by the Antigravity CLI is decoded instead of rejected.

### Added

- **Gemini 4 Argon.** Paid Pro plans get a separate weekly Argon quota. It shows as an ARGON lane next to Gemini and Claude · GPT.

### Changed

- **7D headline.** The big percentage on each card is the first 7-day window: Gemini 7D on Antigravity, the weekly pool on X. Cards with no 7-day window keep their busiest figure. The readout colour and pulse follow the figure shown; card tone and the character's mood still follow the busiest window, so a nearly spent 5-hour window is still flagged.
- Antigravity's ring draws Gemini first.
- Grouped quota windows put the group name in a leading column (IP cards and the EVA skin), so three groups fit without covering the title.
- Ring cards in a row share one ring size, and the ring characters share one scale and eye line.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.3_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.2 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

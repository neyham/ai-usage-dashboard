## AI Usage Dashboard v0.4.1

First multi-platform release: Windows installers plus Linux and macOS packages,
with the same local-first dashboard for Claude Code, Codex, Grok Build, and
DeepSeek.

### Highlights

- **Windows:** NSIS setup (and MSI when produced), WinGet package line continues
  from `0.4.0`.
- **Linux:** `.deb` and AppImage for amd64, plus `install-linux.sh` (SHA-256
  verified download from GitHub Releases).
- **macOS:** `.dmg` plus `install-macos.sh` (SHA-256 verified).
- Same `0.4.0` product features: adaptive usage windows, Codex banked resets,
  optional Grok Build, zero-to-four panels, offline demo, and Windows WSL
  credential discovery for Claude/Codex/Grok.
- CI builds and tests on Windows, Ubuntu, and macOS before publishing assets.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download from this release:

- [NSIS setup](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.1/AI-Usage-Dashboard_0.4.1_x64-setup.exe)
- [Checksums](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.1/AI-Usage-Dashboard_0.4.1_SHA256SUMS.txt)

WinGet community source may lag briefly after a new GitHub version.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.1/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.1/install-macos.sh | sh
```

Pin with `VERSION=0.4.1` if you use the scripts from `latest` after newer tags
exist.

### Compatibility note

Installers are not code-signed. Live mode reads credential formats and usage
endpoints used by provider CLI tools; some are undocumented and can change.
Screensaver and scheduled-idle helpers remain Windows-only. Grok is disabled by
default until enabled in settings.

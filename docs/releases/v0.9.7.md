## AI Usage Dashboard v0.9.7

A security maintenance release that updates SQLite and `rustix` dependencies so all RustSec audit checks pass cleanly.

### Security

- **Bundled SQLite update (`RUSTSEC-2026-0459` / `CVE-2026-119375`).** Updated `rusqlite` from 0.32.1 to 0.41.1 (`libsqlite3-sys` 0.39.1).
- **`rustix` update (`RUSTSEC-2026-0486`).** Updated `rustix` from 1.1.4 to 1.1.6.

### Installation

- **Windows x64:** NSIS `.exe` or MSI. The WinGet community index may lag this release.
- **Linux x64:** DEB or AppImage. AppImage extract-and-run is an alternative when FUSE is unavailable.
- **macOS Apple Silicon:** DMG. No Intel macOS installer is included.

The `install-linux.sh` and `install-macos.sh` helpers are also attached. Verify downloads against `AI-Usage-Dashboard_0.9.7_SHA256SUMS.txt`.

### Compatibility and limits

- The release workflow tests upgrades from the published 0.9.6 packages, startup with synthetic data, repeat install or repair, and executable removal. Renderer interaction tests run separately in Chromium.
- Installers remain unsigned/not notarized; system trust prompts are not covered by CI.

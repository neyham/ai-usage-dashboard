## AI Usage Dashboard v0.4.0

Local-first Windows dashboard release with adaptive usage windows, optional
Grok Build tracking, and aligned WSL credential discovery for Claude, Codex,
and Grok.

### Highlights

- Adaptive Codex/Claude windows: show only windows the provider returns (5H
  and/or 7D), including weekly-only accounts without a fake empty 5H row.
- Codex banked-reset count and earliest known expiry when available.
- Opt-in Grok Build provider: server-reported period, reset time, subscription
  tier, optional monthly allowance, and official-CLI session renewal.
- Zero-to-four-panel adaptive layouts and fullscreen three-column validation.
- Codex credential discovery aligned with Claude/Grok on Windows: native
  `%USERPROFILE%\.codex\auth.json`, then default Ubuntu WSL home, plus bounded
  `wsl:<distro>:<absolute-path>` overrides.
- Offline demo fixtures restore dual-window Codex (5H + 7D) while weekly-only
  remains a dedicated UI regression case.

### Install

After the GitHub Release is published:

- [v0.4.0 NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.0/AI-Usage-Dashboard_0.4.0_x64-setup.exe)
- [v0.4.0 SHA-256 checksum](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.4.0/AI-Usage-Dashboard_0.4.0_SHA256SUMS.txt)

Or via WinGet once the community-source version update is published:

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

The installer is not code-signed, so Windows SmartScreen may require explicit
confirmation.

### Compatibility note

Live mode reads credential formats and usage endpoints used by provider CLI
tools. Some are undocumented and may change without notice. The offline demo has
no dependency on those endpoints. Grok is disabled by default until the user
enables it in settings.

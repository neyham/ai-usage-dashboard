## AI Usage Dashboard v0.8.6

This release keeps a Grok weekly window visible when unified billing omits the
usage percentage, and renames the Cursor lanes to match CodexBar.

### Highlights

- **Grok unknown percentage:** a credits response with a weekly period but no
  `creditUsagePercent` stays nominal. The reset time is shown and the
  percentage stays unknown (`--`). A monthly `0/0` allowance is not drawn as
  zero usage.
- **Cursor lane names:** Total, Cursor, and Third Party. These are the same
  three `usage-summary` fields as before (`totalPercentUsed`,
  `autoPercentUsed`, `apiPercentUsed`).

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.6/AI-Usage-Dashboard_0.8.6_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

On Omarchy / Hyprland, extract the AppImage and launch against host
`webkit2gtk-4.1` with `GDK_BACKEND=x11` and `GDK_SCALE` from `hyprctl monitors`.
See the README Omarchy section.

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.6 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.6) and accompanied by `AI-Usage-Dashboard_0.8.6_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.

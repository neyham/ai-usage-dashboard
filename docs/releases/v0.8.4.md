## AI Usage Dashboard v0.8.4

This release fixes Cursor `AUTH FORBIDDEN` when the local session cookie is
still accepted by cursor.com over OpenSSL, but the dashboard's rustls client
was rejected.

### Highlights

- **OS TLS for Cursor:** `usage-summary` and Grok Bot use HTTP/1.1 with the
  platform TLS stack (OpenSSL / Secure Transport / SChannel) instead of the
  shared rustls client.
- **Request shape:** `GET /api/usage-summary` sends `Origin: https://cursor.com`
  again, matching 0.8.2. Cookie values try decoded `userId::token` first, then
  the CodexBar `userId%3A%3Atoken` form.
- **Rejected encodings:** a 401/403/4xx on one cookie encoding tries the next
  encoding and the next local login instead of stopping.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.4/AI-Usage-Dashboard_0.8.4_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.4 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.4) and accompanied by `AI-Usage-Dashboard_0.8.4_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.

## AI Usage Dashboard v0.8.5

This release points Antigravity Gemini quota at the same daily Cloud Code host
that CodexBar and `agy` use. The unprefixed host answers with dummy remaining
fractions, so the dashboard could show ~2% weekly / 0% 5-hour used while the
same Google login was already near the real limits.

### Highlights

- **Antigravity quota host:** `retrieveUserQuotaSummary` now calls
  `daily-cloudcode-pa.googleapis.com`. Plan lookup still uses `cloudcode-pa`.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.5/AI-Usage-Dashboard_0.8.5_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

On Omarchy / Hyprland, extract the AppImage and launch against host
`webkit2gtk-4.1` with `GDK_BACKEND=x11` and `GDK_SCALE` from `hyprctl monitors`.
See the README Omarchy section.

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.5 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.5) and accompanied by `AI-Usage-Dashboard_0.8.5_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.

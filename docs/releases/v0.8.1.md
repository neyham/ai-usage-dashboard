## AI Usage Dashboard v0.8.1

This release shows Grok Bot quota on the Cursor card. Included, Auto, and API
stay as they are. A missing Bot response does not fail the Cursor panel.

### Highlights

- **Grok Bot on Cursor:** the same `GetSandUsageStatus` feed the Telegram
  daily-monitor uses. Bot is attached in parallel; parse or HTTP failure leaves
  Included / Auto / API unchanged.
- **Reset labels:** Cursor Included and Auto share one billing-cycle reset
  instead of printing the same time twice. Usage bars keep even row height.
- **Mock / demo:** judge-demo and `mockMode=normal` include a synthetic Grok Bot
  window.

### Install

#### Windows

```powershell
winget install --id neyham.AIUsageDashboard --exact --source winget
```

Or download the [NSIS installer](https://github.com/neyham/ai-usage-dashboard/releases/download/v0.8.1/AI-Usage-Dashboard_0.8.1_x64-setup.exe).

Community WinGet indexes can lag a new GitHub release.

#### Linux

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-linux.sh | sh
```

#### macOS

```sh
curl -fsSL https://github.com/neyham/ai-usage-dashboard/releases/latest/download/install-macos.sh | sh
```

All published assets are listed in the [v0.8.1 GitHub Release](https://github.com/neyham/ai-usage-dashboard/releases/tag/v0.8.1) and accompanied by `AI-Usage-Dashboard_0.8.1_SHA256SUMS.txt`.

Installers are unsigned. Screensaver and scheduled-idle helpers remain
Windows-only.

Cursor stays off by default. Enable it from **Display Settings** (gear) or set
`enabledProviders.cursor` to `true`.
